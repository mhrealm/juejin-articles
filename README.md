### javascript

#### map-usage

- [MapDemo.vue](https://github.com/mhrealm/juejin-articles/blob/main/javascript/map-usage/MapDemo.vue)：使用 `reactive(new Map())` 管理商品勾选状态，演示 `set`、`delete`、`clear`、`has`、`size` 等 Map 操作在 Vue 3 响应式中的用法。
- [NormalDemo.vue](https://github.com/mhrealm/juejin-articles/blob/main/javascript/map-usage/NormalDemo.vue)：使用 `ref([])` 和 checkbox 的 `v-model` 保存选中的商品 id，用来对比数组方案和 Map 方案的差异。
- [OrderMerge.vue](https://github.com/mhrealm/juejin-articles/blob/main/javascript/map-usage/OrderMerge.vue)：使用 `Map` 按 `orderId` 记录用户编辑过的订单字段，演示接口数据刷新后如何保留本地编辑状态。
